## Example 1: Conveyor Reducer Pinion Mesh

Calculating tooth forces for input pinion shaft design.

**Inputs**
- Transmitted power: $P = 11.0\text{ kW}$
- Pinion speed: $n = 1450\text{ rpm}$
- Pitch diameter: $d = 85\text{ mm}$
- Normal pressure angle: $\alpha_n = 20^\circ$
- Helix angle: $\beta = 14^\circ$

**Outputs**
- Torque: $T = 72.45\text{ N}\cdot\text{m}$
- Tangential force: $F_t = 1704.7\text{ N}$
- Radial force: $F_r = 639.2\text{ N}$
- Axial force: $F_a = 425.0\text{ N}$

## Example 2: High-Torque Extruder Gear

Resolving heavy shock load reactions on a low-speed spur bull gear.

**Inputs**
- Output torque: $T = 4500\text{ N}\cdot\text{m}$
- Pitch diameter: $d = 600\text{ mm}$
- Pressure angle: $\alpha = 20^\circ$, Helix angle: $\beta = 0^\circ$

**Outputs**
- Tangential force: $F_t = 2000 \times 4500 / 600 = 15000.0\text{ N}$ ($15.0\text{ kN}$)
- Radial separating force: $F_r = 15000 \times \tan(20^\circ) = 5459.6\text{ N}$ ($5.46\text{ kN}$)
- Axial force: $F_a = 0.0\text{ N}$
