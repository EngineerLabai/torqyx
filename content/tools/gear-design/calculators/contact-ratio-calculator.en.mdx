## Calculation Explanation

<Callout type="info" title="How to use">
<StepList title="Step-by-step contact ratio analysis" steps={["Enter normal module (m_n), tooth counts (z1, z2), and helix angle (β)", "Specify normal pressure angle (α_n), face width (b), and addendum coefficient (ha*)", "Evaluate transverse contact ratio (e_α), overlap contact ratio (e_β), and total contact ratio (e_γ)"]} />
</Callout>

<Formula label="Gear Contact Ratio (ISO 21771 / ISO 6336)">
m_t = m_n / cos(β)
α_t = atan(tan(α_n) / cos(β))
p_b = π · m_t · cos(α_t)
e_α = (√(ra1² - rb1²) + √(ra2² - rb2²) - a · sin(α_t)) / p_b
e_β = (b · sin(β)) / (π · m_n)
e_γ = e_α + e_β
</Formula>

**Assumptions**
- Standard full-depth involute gear geometry (ha* = 1.0, c* = 0.25).
- Zero profile shift (x1 = x2 = 0); uncorrected operating center distance a = m_t · (z1 + z2) / 2.
- External cylindrical spur or helical gear pairs.

**Units**
- Normal module (m_n), transverse module (m_t), base pitch (p_b), face width (b), center distance (a): mm
- Normal pressure angle (α_n), transverse pressure angle (α_t), helix angle (β): degrees
- Contact ratios (e_α, e_β, e_γ): dimensionless

**Engineering Standards**
- ISO 21771:2007 (Gears — Cylindrical involute gears and gear pairs — Concepts and geometry)
- ISO 6336-1:2019 (Calculation of load capacity of spur and helical gears)
- DIN 3960 (Definitions, parameters and equations for involute cylindrical gears and gear pairs)

<Callout type="warning" title="Minimum Contact Ratio Requirements">
For smooth kinematic handoff without shock loading, standard spur gears require e_α ≥ 1.20 (ideally ≥ 1.40). For high-speed helical gearing, an axial overlap ratio e_β ≥ 1.0 ensures continuous helical tooth engagement, drastically suppressing gear whine and noise.
</Callout>

## Examples

### Example 1: Helical Gear Pair High-Speed Transmission

Evaluating contact ratios for a helical speed reducer stage.

**Inputs**
- Normal module m_n = 2.0 mm
- Pinion teeth z1 = 18, Gear teeth z2 = 54
- Normal pressure angle α_n = 20°, Helix angle β = 15°
- Face width b = 35 mm, Addendum coefficient ha* = 1.0

**Outputs**
- Transverse module: m_t = 2.0 / cos(15°) = 2.0706 mm
- Transverse pressure angle: α_t = atan(tan(20°)/cos(15°)) = 20.647°
- Base pitch: p_b = π × 2.0706 × cos(20.647°) = 6.085 mm
- Profile contact ratio: e_α = 1.573
- Face overlap ratio: e_β = (35 × sin(15°)) / (π × 2.0) = 1.442
- Total contact ratio: e_γ = 1.573 + 1.442 = 3.015
- Smooth load transfer guaranteed (e_γ &gt; 3.0 indicates three pairs of teeth in concurrent contact).

### Example 2: Standard Spur Gear Mesh (β = 0°)

Verifying profile contact ratio for an electric winch drivetrain.

**Inputs**
- Normal module m_n = 4.0 mm
- Pinion teeth z1 = 19, Gear teeth z2 = 76
- Normal pressure angle α_n = 20°, Helix angle β = 0°
- Face width b = 40 mm

**Outputs**
- Profile contact ratio: e_α = 1.685
- Overlap contact ratio: e_β = 0.000 (spur gear)
- Total contact ratio: e_γ = 1.685
- Adequate margin above the minimum allowable threshold of 1.20.
